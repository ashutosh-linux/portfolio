# Ashutosh Kumar — Developer Portfolio

A modern, dark, cyber-minimalist portfolio built with **React 19 + Vite + Tailwind CSS v4 + Framer Motion + Lucide React**.

Every project card links directly to its repository under [`github.com/ashutosh-linux`](https://github.com/ashutosh-linux), opening in a new tab with `target="_blank" rel="noopener noreferrer"`.

---

## Quick start

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
npm run preview  # preview the production build
```

Node 18+ is required (Node 20+ recommended).

## Editing content

Open **`src/data/portfolio.js`** — it is the single source of truth for the profile,
stats, skills, projects, certifications and experience. Components read from it only.

Repository URLs are generated by a helper so the username can never drift:

```js
export const GITHUB_USER = 'ashutosh-linux';
export const repo = (name) => `https://github.com/${GITHUB_USER}/${name}`;
```

To add a project, append an object to the `projects` array:

```js
{
  id: 'my-repo',
  title: 'My Repo',
  repoName: 'my-repo',
  url: repo('my-repo'),
  description: 'What it does, in one sentence.',
  tags: ['Python', 'FastAPI'],
  category: 'backend',        // ai | backend | cloud | security | fullstack
  icon: 'Activity',           // must be registered in src/lib/icons.js
  featured: false,
}
```

Adding a new icon means adding it to both the import list and the
`iconRegistry` object in `src/lib/icons.js`.

## Before you deploy — two things to add

1. **Resume PDF.** The header "Resume" button downloads
   `public/Ashutosh-Kumar-Resume.pdf`. Drop your PDF into `public/` under exactly
   that filename, or change `RESUME_URL` at the top of `src/components/Navbar.jsx`.

2. **Contact form backend (optional).** The form validates client-side and then
   hands the message to the visitor's own mail client via `mailto:`. To send
   through a service instead, replace the `mailto:` block inside `onSubmit` in
   `src/components/Contact.jsx` with a `fetch` POST to Formspree, EmailJS,
   Web3Forms or your own endpoint.

## Design language

| Token | Value | Used for |
| --- | --- | --- |
| Background | `#07070a` → `#0f1016` | Obsidian base with radial gradient wash |
| Card surface | `#13141f` @ 60% + `backdrop-blur-lg` | Glassmorphic panels |
| Borders | `border-white/10` → `hover:border-cyan-500/50` | Hairline edges |
| Accent 1 | `#06b6d4` neon cyan | AI / GenAI |
| Accent 2 | `#8b5cf6` electric violet | Cloud / Backend |
| Accent 3 | `#10b981` emerald mint | Systems / Security |
| Display font | Space Grotesk | Headings |
| Body font | Inter | Copy |
| Mono font | JetBrains Mono | Code, labels, metadata |

Tokens are declared in the `@theme` block of `src/index.css` (Tailwind v4 uses
CSS-first configuration — there is no `tailwind.config.js`).

Motion: staggered scroll reveals, magnetic buttons, 3D card tilt with a cursor
spotlight, a scroll-linked timeline rail, and a live canvas dot matrix that
reacts to the pointer. Everything collapses gracefully under
`prefers-reduced-motion: reduce`, and pointer effects are disabled on
coarse-pointer (touch) devices.

## Accessibility & responsiveness

- Semantic landmarks (`header`, `main`, `nav`, `footer`, `section`) with skip-safe headings.
- Visible focus rings, `aria-label`/`aria-pressed`/`aria-selected` on interactive controls.
- Form fields wired to labels with `aria-invalid` and `aria-describedby` error messaging.
- Mobile-first layout: single column → 2-up at `sm` → 3-up at `lg`; no horizontal scroll.
- Mobile navigation sheet locks body scroll while open.

## Deploying

The build is fully static. Any of these work out of the box:

```bash
npm run build        # outputs to dist/
```

- **Vercel / Netlify** — framework preset "Vite", build `npm run build`, output `dist`.
- **GitHub Pages** — `vite.config.js` already sets `base: './'`, so `dist/` can be
  published from any subpath.
